# Changelog

## 1.0.0 — Initial Release

- **Search and Open in Bloom** — File search with Bloom as the primary action, works as a Fallback Command
- **Open Clipboard Path in Bloom** — Opens paths from selected text or clipboard
- **Open Finder Selection in Bloom** — Sends selected Finder items to Bloom
- Fallback Command support — your Raycast root search text carries over automatically
- Multi-word AND matching for file search queries
